
comandos base para laboratorio


Verificar que Node esta instalado
	
	node --versión


Ubicar los archivos descargados

	cd Downloads
	cd Descargas
	dir



Crear la carpeta y mover los archivos

	mkdir lab-jwt
	move server.js lab-jwt
	move decodificar.js lab-jwt
	move server-solucion.js lab-jwt


Entrar a la carpeta


	cd lab-jwt


Verificar que estan los tres archivos:

	dir




Arrancar el servidor


	node server.js




Abrir una segunda terminal, esto para ejecutar las peticiones

register

	Invoke-RestMethod -Method POST -Uri http://localhost:3000/auth/register -ContentType "application/json" -Body 	'{"username":"ana","email":"ana@test.com","password":"1234"}'


Posible response: Invoke-RestMethod : Error en el servidor remoto: (409) Conflicto, validar si ya quedo registrado


Si ya esta, es decir, si sigue generando conflicto, realizar login, en caso de pasar el register, no es necesario enviarlo nuevamente

	Invoke-RestMethod -Method POST -Uri http://localhost:3000/auth/login -ContentType "application/json" -Body '{"email":"ana@test.com","password":"1234"}'


Almacenar Token


	$token = (Invoke-RestMethod -Method POST -Uri http://localhost:3000/auth/login -ContentType "application/json" -Body 	'{"email":"ana@test.com","password":"1234"}').token


verificar

	$token



validamos para obtener tareas


	Invoke-RestMethod -Method GET -Uri http://localhost:3000/tasks


posible response Invoke-RestMethod : Error en el servidor remoto: (401) No autorizado.


Añadimos token

	Invoke-RestMethod -Method GET -Uri http://localhost:3000/tasks -Headers @{Authorization="Bearer $token"}


response esperado

	tasks
	-----
	{}


Creamos una tarea


	Invoke-RestMethod -Method POST -Uri http://localhost:3000/tasks -ContentType "application/json" -Headers @{Authorization="Bearer $token"} -Body 	'{"title":"Estudiar JWT","description":"Practicar"}'


Al momento de crearla validamos listándola


	Invoke-RestMethod -Method GET -Uri http://localhost:3000/tasks -Headers @{Authorization="Bearer $token"}
