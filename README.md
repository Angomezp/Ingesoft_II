# Laboratorio REST por consola y SSH

# Descripción del proyecto

Este proyecto documenta un laboratorio enfocado en el consumo y prueba de una API REST hecha con Node.js, junto con una segunda parte de conexión remota por SSH desde un dispositivo móvil. El repositorio incluye el código del servidor, los comandos usados para probar los endpoints y las capturas que muestran el resultado de cada paso.

**Contenido:**

- `/Laboratorio:`
  - `Laboratorio.md:` Documento principal del laboratorio. Incluye la explicación del flujo de trabajo, las pruebas realizadas con los endpoints, la configuración de SSH y las evidencias en imágenes.
  - `server.js:` Servidor REST desarrollado con Node.js para registrar usuarios, iniciar sesión, generar token y gestionar tareas.
  - `images/:` Carpeta con capturas de pantalla y evidencias del proceso, tanto de la primera parte como de la conexión por SSH.

**Resumen:**

- Primera parte del laboratorio: pruebas locales de la API REST con `node server.js` y comandos de PowerShell.
- Segunda parte del laboratorio: configuración de OpenSSH y conexión remota desde `Termius` en un dispositivo móvil.
